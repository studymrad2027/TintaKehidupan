# Daily

A tap-first daily planner and journal that runs in the browser.

- **Today:** three colour-coded lanes (Life, Study, Work), a progress ring, a forgiving streak, and a 10-second evening check-in (mood, chips, optional note). Unfinished tasks carry over to the next day.
- **Bills:** set a bill once and it repeats monthly, with a "due soon" strip on the Today screen. Marking a bill paid logs it to Spend.
- **Spend:** pick a category, type an amount, done. Weekly and monthly totals.
- **Week:** active days, wins, and spending summary, plus JSON backup and restore.

## Your data

Everything is stored in your browser's local storage on your own device. Nothing is uploaded. Use **Week > Export** to keep a backup, since clearing browser data erases it.

## Install on your phone

Open the published page in your phone browser, then use **Add to Home Screen** (iPhone: Share > Add to Home Screen; Android: menu > Install app). It then opens full-screen like an app and works offline.
